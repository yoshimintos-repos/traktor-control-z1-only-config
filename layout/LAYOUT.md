# Begleit-Layout „Z1MK2 Layout fuer Loop-Mod.tsi“

Controller-Manager-Layout (Overmapping) für den Z1 MK2, abgestimmt auf den Mod. Shift = Filter-Taste (Modifier 1), Browser-Modus = Modifier 3.

| Taste | ohne Shift | mit Shift |
|---|---|---|
| Gain-Knopf | EQ-Mode: Loop Size · Stem-Mode: Drums *(Mod)* | Loop Size *(Mod)* |
| EQ-Taste links | EQ-Mode | Loop setzen/beenden Deck A *(Mod)* |
| Stems-Taste links | Stem-Mode | Only Browser an/aus und Browser-Modus an/aus |
| EQ-Taste rechts | EQ-Mode | – |
| Stems-Taste rechts | Stem-Mode | Loop setzen/beenden Deck B *(Mod)* |
| Channel-FX-On (L/R) | Play/Pause · im Browser-Modus: Track laden | Seek auf Track-Anfang |
| FX 1 / FX 2 | Effekt wählen | Sync Deck A / B |
| Mode | Deck A/B ↔ C/D | – |
| HP-Cue (L/R) | Vorhören · im Browser-Modus: Liste blättern | im Browser-Modus: Ordnerbaum blättern |

Bei allen Zeilen, die nur mit Shift aktiv sind, und bei der Shift-Zeile ist „Override factory map“ ausgeschaltet. So kann der Mod die Tasten beleuchten und die Shift-Taste erkennen.
